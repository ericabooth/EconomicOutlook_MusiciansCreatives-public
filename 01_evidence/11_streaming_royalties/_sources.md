## Known gaps / blockers (see also `_findings.md`)
1. **SoundExchange full 2015-2023 annual time series** — only 2022-2024 (audited) plus scattered press-release figures for 2015, 2019 were assembled. A complete panel would require pulling each year's individual audited annual report from soundexchange.com.
2. **MLC black-box figure discrepancy** — a Feb 2023 Digital Music News piece cites "$561MM unmatched" for 2021, which doesn't cleanly reconcile with the $397-424M figures used elsewhere; not resolved in this pass.
3. **MIDiA per-stream figures** — a specific current-year table was only found second-hand (via a blog aggregator), not pulled directly from a MIDiA-authored report/PDF. Recommend a follow-up to access an actual MIDiA report before citing a specific number under MIDiA's name.
4. **AFM Local 65-699 (Houston) current membership count** — not publicly available; would need a direct ask to the local or an AFM/OLMS (Dept. of Labor LM-2) filings pull.
5. **ASCAP/BMI Texas-specific member counts** — confirmed not published; no viable public workaround found besides BLS OEWS occupational employment estimates for "Musicians and Singers" (not pulled in this pass — flagged as a possible next data source if a firmer Texas musician headcount is needed for the allocation math).
6. **Loud & Clear exact numeric extraction** — the live takeaways page uses interactive/graphical presentation of its "10 takeaways," so exact figures were cross-validated via multiple trade-press write-ups rather than pulled as raw text directly off Spotify's page. If a direct-quote citation of Spotify's own page text is required, a browser screenshot/capture would be a useful follow-up.
